# Security Policy
Security contact: @Ranoes (ranokarnoubisoft@gmail.com)

## Supported Versions

Security fixes go into the latest stable release only (`1.0.x`). Update to it before reporting.

## Reporting a Vulnerability

- Please report vulnerabilities privately via GitHub Security Advisories at [https://github.com/Ranoes/echovena/security/advisories](https://github.com/Ranoes/echovena/security/advisories) or by emailing ranokarnoubisoft@gmail.com directly.
- Include details that help us reproduce and assess impact: EchoVena version, OS, installation method, minimal reproduction steps, and any relevant logs (with secrets and tokens stripped).
- You can expect an acknowledgment within 3 business days and status updates at least weekly until resolution.
- If the issue is confirmed, we will coordinate a fix and release notes before public disclosure.
